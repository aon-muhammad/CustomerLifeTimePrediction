# Customer Lifetime Value (CLV) Prediction

An end-to-end Machine Learning and Deep Learning project designed to predict **Customer Lifetime Value (CLV)** in the auto insurance sector using demographic, policy, financial, and vehicle attributes.

---

## 📌 Project Overview

Customer Lifetime Value (CLV) is a critical metric for insurance companies, representing the total revenue a business can expect from a single customer account throughout their relationship. Accurate CLV prediction enables insurance providers to:
- Optimize customer acquisition costs and retention strategies.
- Tailor marketing offers and renewal policy types.
- Identify high-value customer segments for personalized risk management.

This repository contains data analysis, exploratory data visualization, feature engineering, feature selection via Mutual Information, and predictive modeling (Deep Learning ANN & Skewness-corrected regression models).

## 🛠 Preprocessing & Feature Engineering Pipeline

1. **Date Processing & Feature Extraction**:
   - `Effective To Date` parsed into `datetime` object.
   - Extracted temporal features: `Month`, `date`, `year`.

2. **Categorical Encoding**:
   - **Binary Encoding**: `Response` (`Yes` $\rightarrow$ 1, `No` $\rightarrow$ 0) and `Gender` (`M` $\rightarrow$ 1, `F` $\rightarrow$ 0).
   - **Ordinal Encoding**: `Coverage` (`Basic` $\rightarrow$ 0, `Extended` $\rightarrow$ 1, `Premium` $\rightarrow$ 2), `Education` (`High School or Below` $\rightarrow$ 0 to `Doctor` $\rightarrow$ 4), and `Vehicle Size` (`Small` $\rightarrow$ 0, `Medsize` $\rightarrow$ 1, `Large` $\rightarrow$ 2).
   - **One-Hot Encoding**: Applied to non-ordinal categorical attributes (`Vehicle Class`, `EmploymentStatus`, `Policy Type`, `Policy`, `Renew Offer Type`, `Sales Channel`, `Marital Status`, `State`, `Location Code`) using `pd.get_dummies(drop_first=True)`.

3. **Zero-Income Handling**:
   - Feature `Income_Zero` engineered to flag zero income records (`Income == 0`).

4. **Skewness Correction & Power Transformations**:
   - Positively skewed numerical features ($\text{skew} \ge 1.0$) transformed using log transformation `np.log1p()`.
   - Negatively skewed features transformed using `PowerTransformer(method='yeo-johnson')`.
   - *Key Discovery*: Transforming the heavily skewed target variable `Customer Lifetime Value` ($\text{skewness} \approx 3.03$) prevents extreme outlier distortion and drastically improves model variance explanation.

5. **Feature Scaling**:
   - Features standardized using `StandardScaler` to ensure zero mean and unit variance for neural network training stability.

## 📈 Model Architecture & Performance Evaluation

### Baseline Artificial Neural Network (ANN)

Built with Keras / TensorFlow `Sequential` API:
- **Input Layer**: `Dense(64, activation='relu')` matching feature dimension.
- **Hidden Layers**: `Dense(64, activation='relu')` $\rightarrow$ `Dense(32, activation='relu')`.
- **Output Layer**: `Dense(1)` for continuous regression prediction.
- **Optimizer**: `Adam`
- **Loss Function**: `Mean Squared Error (MSE)`
- **Metrics**: `Mean Absolute Error (MAE)`

### Performance Metrics Comparison

| Model Setup | MAE | RMSE | $R^2$ Score | Key Note |
| :--- | :--- | :--- | :--- | :--- |
| **Initial Raw Target Baseline** | ~4,042 | ~6,566 | **0.163** | Loss dominated by high-CLV outliers |
| **Skewness Corrected Model** | -- | -- | **0.720+** | Log-transforming target & features resolves non-linear scale |

## 🔍 Feature Selection via Mutual Information

To determine the most influential predictors of Customer Lifetime Value, Mutual Information Regression (`mutual_info_regression`) was computed:

### Top Feature Rankings
1. `Monthly Premium Auto` (~1.65)
2. `Total Claim Amount` (~1.07)
3. `Income` (~0.88)
4. `Number of Policies` (~0.78)
5. `Months Since Policy Inception` (~0.58)
6. `date` (~0.44)
7. `Months Since Last Claim` (~0.44)
8. `Coverage` (~0.32)
9. `Response` (~0.30)

*Low-impact predictors* (such as individual policy sub-tiers or specific state dummies with near-zero mutual information) can be pruned during feature selection to reduce model complexity and overfitting risk.
